# What is this?
This is a project for a mini MIDI keyboard attachment for the Korg NTS-1 mini synthesizer I made circa 2021. It has two octaves of keys with octave switch buttons on either end. 

# What's in it?
This repo contains the KICAD files, arduino sketch to program the ATTiny45 and 3D stl files for the body attachment. I used an arduino mini to program the ATTiny as I did not have a suitable programmer at the time. Note, due to an error the footprint of the ATTiny is too narrow to fit the SOP package. Either edit the project file, or bend the pins of the MCU to fit it onto the board.
